About this prototype

QueueSense AI uses a pretrained YOLO person detector to count people in sampled video frames. The waiting-time value is a formula-based baseline, and crowd thresholds are configurable prototype values—not official safety guidance.

Use only video sources you are authorized to access. The app is designed to run locally on this computer.
